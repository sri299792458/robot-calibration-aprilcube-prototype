# Accepted printed carrier

This folder contains only the accepted carrier used by the
[current V7 torso mount](../../artifacts/g1_mount_v7/README.md):

- `carrier_white_body.stl`
- `carrier_black_inlay.stl`
- `carrier_multicolor_h2d.3mf`
- `design_manifest.json`: carrier definition and frozen mounting coordinates

The already printed carrier does not need to be printed again. Its original
mesh and 3MF bytes are unchanged. The previous V6 side frames, coupons and
generator have been removed. The current structural parts and fit coupons
are in `artifacts/g1_mount_v7/` and `artifacts/g1_coupon_r2/`.
